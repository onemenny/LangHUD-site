Version 0.2.1

2026-11-26

Added

  • Click in a text box and the HUD shows your current keyboard language (optional, in Settings).

Fixed

  • The Settings window is no longer cut off at the sides on some Macs.

Version 0.2.0

2026-11-26

Added

  • Auto-correct as you type: an optional setting that fixes words typed in the wrong keyboard language as you go.
  • Convert text without selecting it first: with nothing selected, the shortcut converts the line you are on.
  • A new way to trigger a conversion: double-tap a modifier key.
  • LangHUD stays quiet while Do Not Disturb or a Focus is on.
  • Set a keyboard layout per app.
  • More reminder looks, per language.

Changed

  • Settings take effect immediately.
  • A tidier menu-bar menu and Settings window.
  • Smaller fixes and polish throughout.

Version 0.1.0

2026-11-18

Added

  • An on-screen reminder of the keyboard language you are typing in, with an optional spoken cue.
  • Fix text typed in the wrong keyboard language with one shortcut.
  • A 14-day free trial, and update checks inside the app.
